# Tạo ảnh nhật ký cuộc gọi

Web app tĩnh dùng để nhập số điện thoại, giờ, ngày và xuất ảnh PNG theo template.

## Cách publish miễn phí lâu dài bằng GitHub Pages

1. Tạo một repository mới trên GitHub.
2. Upload toàn bộ file trong thư mục này lên repository đó.
3. Vào `Settings` -> `Pages`.
4. Chọn `Deploy from a branch`.
5. Chọn branch `main` và folder `/root`.
6. Bấm `Save`.

Sau vài phút, GitHub sẽ cấp link dạng:

```text
https://ten-user.github.io/ten-repo/
```

Mở link đó trên điện thoại rồi thêm vào màn hình chính:

- Android Chrome: menu ba chấm -> `Add to Home screen`.
- iPhone Safari: nút Share -> `Add to Home Screen`.

App là static/PWA, không cần server, không cần database, không có chi phí hosting trên GitHub Pages.
